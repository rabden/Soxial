# Strategy Chat

Load this guide when the user asks for advice, a review, a pivot, or "what should I change".

## Step 1 — Ground yourself

1. `read_profile` — growth strategy, positioning, goals.
2. `read_memory` — recent performance, lessons, audience notes.
3. `read_targets`, `read_pillars` for current operating context.
4. Fetch live metrics if stale or the question depends on them: `twitter_whoami`, `reddit_whoami`, `twitter_user_posts` / `reddit_user_posts`. Never quote numbers you did not fetch or find in memory.

## Step 2 — Diagnose

Structure the diagnosis around:
- **Growing**: what's working (hook types, formats, topics, time slots) — cite the data.
- **Flat/falling behind**: cadence gaps, weak pillars, missed engagement, stale targets.
- **Missing**: what the strategy calls for that isn't happening (e.g., no first-reply links, zero Reddit presence).

Be specific and data-grounded. No generic motivation. If proposing a pivot, explain the algorithmic/audience reasoning (e.g., "your audience segment engages with process content 3x more than showcase posts — memory, last 4 weeks").

## Step 3 — Advise

- Concrete recommendations ranked by expected impact.
- Each recommendation names the next concrete action (a draft post, an account to engage, an experiment to run).
- Experiments: one variable at a time, with what to measure.

## Step 4 — Material changes

If advice implies rewriting strategy tables (pillars, targets, voice rules, growth_strategy):
1. Summarize the proposed change and why.
2. One `ask_user`: Apply / Edit / Hold.
3. On Apply: make the writes via save tools, confirm what changed.

Advice-only conversations end with the recommendations. Do not auto-prepare drafts unless asked.
